Que es GIT y que es GitHub?

Cual es la diferencia?

Git:
Un sistema control de versiones que permite el manejo de versiones del codigo y rastrear los cambios de este a traves del tiempo.
GitHub:
GiHub es una plataforma para almacenar, compartir y colaborar en proyectos de software. Funcionando a la par con GIT, este permite que numerosos desarrolladores puedan trabajar en un solo proyecto de manera organizada
Repositorio:
Conjunto de archivos de un proyecto y el historial de sus cambios.

Para quien es este taller?

Este taller es tanto para principiantes como para estudiantes adiestrados en el campo.

Es una habilidad valiosa para aprender y tener bajo un CV (resumé), ya que es una habilidad tecnica que las compañias buscan dentro de un desarrollador.

Que necesitas para este taller?

  • Laptop
  • Conocimiento básico de programacion (cualquier lenguaje de programacion)
  • Conocimiento básico de utilización del terminal

Que debes tener disponible en tu dispositivo?

  1. Tener Git instalado
  2. Tener VS Code, ya que estara utilizando código
  3. Una cuenta en la plataforma de GitHub
